# 📦 GestãoPro - Interactive Frontend Showcase

> **Nota:** Este repositório contém a interface interativa e o dashboard do projeto GestãoPro. 
> Para facilitar a visualização sem a necessidade de configurar um ambiente local com MySQL e Flask, 
> esta versão utiliza **dados mockados** (estáticos) no JavaScript.

### 🔗 [Acesse a Demo Online Aqui (GitHub Pages/Vercel)]

---

## 🎯 O que é esta demonstração?
Este projeto é a vitrine visual do **GestãoPro**, um sistema de inventário com previsão de demanda. 
Aqui você pode interagir com:
- **Dashboard Dinâmico:** Gráficos interativos usando Chart.js.
- **UI Responsiva:** Interface focada em usabilidade e eficiência.
- **Simulação de Previsão:** Visualização do motor de regressão linear (mocked).
